# Kaushiki Saxena — React Portfolio

A modern, responsive personal portfolio starter built with React + Vite.

## Included

- Responsive navigation
- Hero section
- About section
- Education / journey timeline
- Project placeholders
- Contact section
- Responsive mobile layout
- Lucide icons
- No backend required

## Run locally

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build for production

```bash
npm run build
npm run preview
```

## Personalize it

Open `src/main.jsx` and update:

- `profile.name`
- `profile.title`
- `profile.institution`
- `profile.city`
- `profile.field`
- `profile.intro`
- Project cards
- Email
- LinkedIn URL
- GitHub URL
- Education timeline

The current content deliberately avoids inventing achievements, internships, skills, or projects that were not provided.
